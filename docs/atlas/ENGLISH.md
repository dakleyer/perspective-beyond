# Atlas documentation language

English is the default language of Atlas documentation, assistant instructions, integration guides, reading controls and generated navigation pages. Documentation is translated in full, retaining its meaning, examples, configuration and references.

Source documents, dialogues, source quotations and the corpus's conceptual readings retain their original language. Source titles and the registered explanations of relationships remain attributable to their original records.

Existing URLs, identifiers, parameter names and accepted configuration values remain stable. An English display label does not rename a stored tag or change a relationship. Legacy serialized headers remain available as compatibility data; current positioning reads the English header and its measured token cost.

The complete institutional reader is available at https://integralmanagement.ch/atlas-reader/ . Its HTML and text instructions are public and navigable without JavaScript or authentication. GitHub retains the canonical source and change history.
