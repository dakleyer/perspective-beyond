Una fuente de pensamiento.
Muchas formas de crear.

Una web para explorar como persona. Una fuente autocontenida para trabajar con tu asistente. Las dos nacen del mismo Atlas.

Elige una lectura y entrega su URL a tu asistente. El archivo ya reúne los textos, sus relaciones, las fuentes y las indicaciones de trabajo. A partir de ahí puedes conversar, preparar una página web, crear un audio, desarrollar un vídeo o dar forma a un documento.

  1. Elige el pensamiento.
    Un documento de entrada, sus fichas y las ideas cercanas que ayudan a comprenderlo.
  2. Entrega una sola URL.
    La selección y la configuración están escritas dentro del archivo.
  3. Pide lo que quieres crear.
    El asistente transforma esa base en conversación, web, audio, vídeo o documento.
