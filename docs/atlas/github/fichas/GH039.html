01K-A01 — Human Capacity / HID Component Verification Record v0.1

La revisión contrasta los estados de disponibilidad humana del componente con su especificación y con las interfaces que lo consumen. Para escalar una decisión importan la competencia, el permiso y el tiempo restante. La deuda de inteligencia humana se observa con una medida separada.
