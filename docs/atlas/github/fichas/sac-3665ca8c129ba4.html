VNext — Ley de gradiente condicionado por objetivo

La revisión sigue una idea operativa: un cambio importa cuando altera el objetivo local a través de una dependencia identificable. Distingue el interés de una oportunidad, el permiso para actuar y la requalificación del marco cuando cambia el contexto.
