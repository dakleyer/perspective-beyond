00K-A20 — Shared-Substrate Mathematical Independence of P1–P6 — v0.1

La demostración construye modelos en un sustrato común para estudiar si cada principio conserva una obligación propia. Los axiomas de coherencia delimitan el universo sobre el que vale la independencia. A22 formula otra pregunta: cuántas firmas diagnósticas pueden realizarse.

Pregunta de lectura
¿Qué axioma de fondo debe conservar cada testigo para que el contraejemplo pertenezca al mismo universo?
