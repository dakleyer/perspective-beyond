CU-HIB-01 — Hibernation and Context Sufficiency: R1 → R2 → R3 (Technical Record)

El escenario examina la reactivación de un privilegio cuando cambia el contexto y una fuente deja de responder. La decisión depende de qué autoridad sigue vigente y qué comprobación puede sostenerse con fuentes disponibles. Es un diseño de investigación para contrastar rutas R1, R2 y R3.

Pregunta de lectura
¿Qué dato permitiría reactivar un permiso concreto sin restaurar todos los privilegios anteriores?
