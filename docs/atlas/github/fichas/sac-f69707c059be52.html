00J — Success Model Case: Proposition-Scoped Provenance — v0.1

Una constancia conserva valor para la proposición que acredita, sea generación, inscripción o atestación. Un derecho o una decisión posterior puede necesitar una base adicional. El modelo vincula cada decisión a la evidencia específica que la sostiene.

Pregunta de lectura
¿Qué acredita exactamente el registro y qué dato adicional necesitaría quien decide?
