# Un control puede aprobar y el sistema seguir fallando

INTERLOCUTOR (pregunta editorial) — ¿Qué significa que todas las casillas de control estén marcadas y la operación produzca un resultado equivocado?
LECTURA DEL DIÁLOGO (síntesis editorial) — UC21 formula un caso de ingeniería que Iván se resiste a suavizar: **cada componente puede cumplir sus controles y el sistema completo puede seguir fallando**. El problema no es necesariamente un controlador defectuoso o un agente desobediente. Puede surgir de dependencias, cambios de contexto, interfaces o condiciones de validez que cada auditoría local dejó fuera de su alcance. Una prueba retrospectiva de un incidente conocido tampoco demuestra que el sistema reconocerá prospectivamente el siguiente régimen sin recibir la respuesta de antemano. Por eso distingue evidencia local, calificación independiente de contexto, revalidación de continuidad y control mínimo suficiente para actuar sin traicionar la misión. Añadir controles indiscriminadamente puede consumir capacidad y trasladar responsabilidad; lo que busca es identificar qué información y qué especificación realmente cierran la brecha de decisión, si es posible hacerlo.
