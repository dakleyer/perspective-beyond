# The Outlook

What the program forecasts about the near future — anchored on its main prediction: that automation, applied to the systems we actually run, produces more inefficiency and more work before it produces fewer jobs.

Document Status — Companion Paper (The Outlook) · Series: Informational Friction (a systems theory)

This paper gathers the forward forecasts of the whole program — across all four series: The Cost of Clarity (information theory), The Attribution Gap (economics), Human Intelligence Debt (organizational theory), and the systems-theory series (Papers 1–3). Each forecast is conditional: it holds only while the falsification test it rests on survives. Those tests are stated in full in the companion refutation paper; here each forecast names the test it depends on so an examiner can follow the thread.
