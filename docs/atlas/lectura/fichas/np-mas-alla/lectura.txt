# Perspective Beyond: cuándo queda corto un marco

Un marco permite medir y decidir, pero responde a las preguntas para las que fue construido. Si cambian las condiciones, conviene revisar qué presupuestos siguen vigentes antes de mejorar la respuesta existente.
