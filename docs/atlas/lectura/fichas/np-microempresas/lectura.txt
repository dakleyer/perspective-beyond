# Microempresarios: mirar el negocio desde otra silla

El Programa de Desarrollo Organizacional proponía observar el mismo negocio como cliente, trabajador, proveedor o vecino. Comparar esas miradas permite descubrir una contradicción entre la promesa del negocio y lo que sucede al visitarlo o trabajar allí.
