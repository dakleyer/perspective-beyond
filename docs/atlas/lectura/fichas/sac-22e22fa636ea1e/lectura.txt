# 00F — Success Model Case: Coherent Shared-Capacity Requalification — v0.1

Cada operador puede conservar una decisión local válida y, aun así, competir por un recurso compartido. El modelo compara el efecto conjunto antes de actuar y vuelve a calificar solo los compromisos afectados, con intervención de quien tiene autoridad sobre el recurso.
