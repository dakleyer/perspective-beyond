```text
python tools/check-atlas-links.py
```

The historical check detects missing cards or relationships, changes to relationship endpoints, lost source associations, previously present texts left empty, duplicates and relationships without a target. Its seven control tests check that it recognises both valid extensions and cases of loss.

These tools read Git revisions in memory and return their results; they create no Atlas backups.
