## Repetir la revisión

Desde un clon del repositorio:

```text
node tools/check-atlas-history.mjs
node tools/check-atlas-history.mjs --self-test
python tools/check-atlas-links.py
```

La comprobación histórica detecta fichas o relaciones ausentes, cambios en los extremos de una relación, asociaciones de fuentes perdidas, textos antes presentes que quedaron vacíos, duplicados y relaciones sin destino. Sus siete pruebas de control comprueban que reconoce tanto las ampliaciones válidas como los casos de pérdida.

Estas herramientas leen las revisiones de Git en memoria y devuelven sus resultados; no crean respaldos del Atlas.
