Weights, tokens and URL configuration

The entry point identifies a document and its cards. Each card has a tag composition. If you choose “aprendizaje: 50, perspectiva: 30, encuentros: 20”, those values guide traversal priority; they are normalised relative to each other.

Tokens measure the selected reading of cards and their relationships. A larger budget allows connected traversal to continue. Closed scope concentrates on one cluster; porous scope crosses a recorded thematic bridge; federated scope traverses the constellation.

In the expanded view you can modify those criteria, copy the configured URL and download the selection. Its JSON retains the cards, relationships and reading accounting to reproduce the map.
