### Adjustments arising from these readings

- Differences in the capitalisation of known keys are resolved against their canonical spelling. An unknown, duplicate or out-of-scope tag prompts a correction; the selector retains the pending allocation rather than replacing it with another.
- The closed Dialogues entry decreases from approximately 505 KB to 8 KB. It links the complete catalogue separately and a brief index with 93 conceptual entries. The content of the 298 reflections and corpus sources is retained.
- The common instructions ask readers to explain the idea and its mechanism first, use readable link titles and integrate dates where they clarify a claim. The technical record is presented separately when the reader requests it.
- Twenty functional checks verify normalisation, numbers, duplicates, unknown keys, scope and preservation of previous map selections. [Functional results](pruebas-funciones.json).

The web reader used in these conversations returned errors for some Pages URLs. The agents recovered the public texts over HTTP and recorded that path. The entry retains the equivalent GitHub route for text readers.

## How to repeat the test

1. Open a new conversation. Paste only one URL from the table and a question. You can ask the assistant to explain where its answer came from and identify the sources it opened.
2. Include a request requiring another area. Check that the assistant identifies the boundary before using the source and proposes a new selection when needed.
3. Ask for an application to a new case. Check that the attributed idea, editorial connection and proposed application remain separate.
4. Repeat with a selector URL and a text profile. For a map, compare the downloaded JSON with the visible selection and verify each arrow's direction in `edges`.

The validation describes behaviour observed in these conversations. The profile indicates how to read the Atlas. Access to each original depends on the assistant's reading capabilities.
