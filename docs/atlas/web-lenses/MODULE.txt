WORDPRESS INTEGRATION\n\nThe module/ directory contains the small display integration installed on the six corpus domains. It does not write article bodies.\n\nReproduce all windows: node docs/atlas/web-lenses/generate.mjs --check\nGenerate JSON to a chosen build directory: node docs/atlas/web-lenses/generate.mjs --out <directory>\n\nThe graph and positioning module remain at docs/atlas/mapa/grafo.json and docs/atlas/positioning.mjs. profiles.json declares the designer configuration for every source page.\n
