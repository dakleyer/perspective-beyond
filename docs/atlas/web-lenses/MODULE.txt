WORDPRESS INTEGRATION

The module/ directory contains the small display integration installed on the six corpus domains. It preserves existing map covers and styling, binds the visible reading to a computed window, and adds links to the same Mind Atlas. It reads the central profiles and prepared selections. It does not write article bodies.

Install the main module directory as mind-atlas-page-windows. On the four custom-template pages described in TEMPLATE-ENTRIES.txt, the optional template-bridge.php plugin supplies the same entry context.

Reproduce all windows:
node docs/atlas/web-lenses/generate.mjs --check

Generate JSON to a chosen build directory:
node docs/atlas/web-lenses/generate.mjs --out <directory>

The graph and positioning module remain at docs/atlas/mapa/grafo.json and docs/atlas/positioning.mjs. profiles.json declares the designer configuration for every source page. Each page is a reading window of the same graph, with its own entry, tag weights and initial reading budget.
