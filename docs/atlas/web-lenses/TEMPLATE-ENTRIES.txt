CUSTOM-TEMPLATE ENTRIES

Four existing page templates (the JubAp.Net and JubAp.us home pages and case timelines) render outside the usual WordPress content and footer hooks.

The optional template-bridge.php display plugin adds the same page context and shared module immediately before the closing body tag. It is restricted to those four paths. Its presence guard prevents duplicate entries. It changes no stored article, theme or map design.

The original NET and US Atlas entry loaders also include a guarded central-module fallback. Native page context takes precedence.
