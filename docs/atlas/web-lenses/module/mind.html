Pesos, tokens y configuración de una URL

El punto de entrada identifica un documento y sus fichas. Cada ficha tiene una composición de etiquetas. Si eliges «aprendizaje: 50, perspectiva: 30, encuentros: 20», esos valores orientan la prioridad del recorrido; se normalizan entre sí.

Los tokens miden la lectura seleccionada de las fichas y sus relaciones. Un presupuesto mayor permite continuar el recorrido conectado. El alcance cerrado se concentra en un clúster; el poroso cruza un puente temático registrado; el federado recorre la constelación.

En la vista ampliada puedes modificar esos criterios, copiar la URL configurada y descargar la selección. Su JSON conserva las fichas, las relaciones y la cuenta de lectura para reproducir el mapa.
