Reductive integration

Homogenisation can remove functions or options carried by local differences.

← Interventions

When it applies

Distinguish loss of capability from retirement of redundant support.

    Reusable capability

    Rationalization should distinguish retiring a redundant implementation from destroying a useful capability; simplification alone does not identify a reductive integration.

    No toda estandarización empobrece, ni toda diversidad debe conservarse. La unidad de evaluación es la función y sus condiciones.
