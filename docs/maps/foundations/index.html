What the record can tell us

Start with the distinction between what happens in an operation and what a model preserves. Follow the conditions under which evidence can support a decision, be reconstructed, or travel into a new setting.

Concepts on this path

  • Constitutive informationAn authorised decision creates a rule, mandate or responsibility.
  • Context versionIdentify which contextual state informed a representation, rule or decision.
  • Contextual admissibilitySpecify the circumstances under which an observation can inform a decision.
  • Demand signalsObservations can inform what users or operations need.
  • Dependency-aware reconstructionRecompute descendants affected by a correction and retain independent results.
  • Diagnosing insufficiency and reconstructing informationShowing that a record is insufficient is different from acquiring a representation that answers the question.
  • Effective non-closure in an open worldA finite run can close its record while the semantic question remains open.
  • Event time and knowledge timeSeparate when an event occurred from when its evidence became available.
  • Existence, encounter and executable opportunityAn option can exist before anyone encounters it or can act on it.
  • Historical and at-use validityA rule can be valid for interpreting a past event and inadequate for a current decision.
  • Logic FieldsLogic Fields is a foundational lens in the initial map for the conditions under which distinctions and inferences remain meaningful.
  • Memory horizonsUse different time windows for local episodes, persistent patterns and regime shifts.
  • Narrative compression of capabilityA compact model or story communicates complex practices and dependencies.
  • Non-observability and prudent isolationWhen critical state is unavailable, isolation can be a bounded protective response.
  • Non-purchase signalsA completed-sale record omits information about choices that did not become sales.
  • Observation expansionAcquire a signal or source that could change a specific decision.
  • Principles P1–P6The foundational theory groups principles that constrain the architectural approach.
  • Process observabilityReconstruct work, events and dependencies from observable evidence.
  • Qualified properties of the residualEvidence can support a bounded claim about the unresolved remainder.
  • Record before admissionPreserve an authorised trace before its classification for possible later admission.
  • Runtime rule plasticityA resident program can revise its operating rules or interpretation under qualified conditions.
  • Shared semantics for an intersectionObservers can compose predicates when question, domain, event, provenance and time match.
  • Similarity-based retrievalRetrieve material close to a query in content or representation.
  • Stable identityRefer to the same operational object across movements, systems and views.
  • Structural AwarenessThe research programme examines what can be known, decided and controlled under partial representations.
  • Sufficient distinctions for a new questionA representation must distinguish states that call for different answers in the new use.
  • The Given Universe AxiomThe axiom frames limits on recovering distinctions that are missing from available records.
  • The Map and the FlowThe published essay examines what can be lost when a representation of work replaces the flow through which value is produced.
  • Unrecoverable remainderSome distinctions are absent from the available output or record.
  • Validity and expiryEvidence and permission have temporal and policy limits.
  • Versioned rules with ownersMaintain each operational rule with its owner, version and effective scope.
  • World, record and missing contextThe operating world differs from the data and categories used to represent it.
