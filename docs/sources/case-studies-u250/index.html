Concepts and methods

  • 01Cross-territory architecture adaptationTransfer a function while redesigning rules, support and incentives for the receiver.↗
  • 02Generative integrationCombine useful differences so the parts can sustain new functions together.↗
  • 03Reductive integrationHomogenisation can remove functions or options carried by local differences.↗
  • 04Capability migration and value captureCapability creation, carriers, operation and value capture can occur in different places.↗

Conceptual connections

  • 01Documented useCross-frontier activationThe Tuxpan mobility account illustrates cross-frontier activation through adaptation: experience from different operating worlds informed a locally constrained architecture.↗
  • 02Possible transferContext handoffA generative boundary can inspire an interface design that shares enough context for safe coordination without requiring both sides to adopt an identical internal model.↗
  • 03Possible transferContribution evidenceA cross-border follow-up should establish whether the same capability was retained, transferred, duplicated or lost before applying an attribution-gap explanation.↗
  • 04AnalogyReusable capabilityRationalization should distinguish retiring a redundant implementation from destroying a useful capability; simplification alone does not identify a reductive integration.↗
