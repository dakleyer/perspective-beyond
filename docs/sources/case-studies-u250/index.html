Concepts and methods

  • Cross-territory architecture adaptationTransfer a function while redesigning rules, support and incentives for the receiver.
  • Generative integrationCombine useful differences so the parts can sustain new functions together.
  • Reductive integrationHomogenisation can remove functions or options carried by local differences.
  • Capability migration and value captureCapability creation, carriers, operation and value capture can occur in different places.
